# Git Workflow Rule

Whenever a new branch is created and changes are committed to it, you MUST also merge those changes into the `main` branch and push the `main` branch to the remote repository.

**Steps:**
1. Create new branch, commit changes, and push the new branch.
2. Checkout `main`.
3. Merge the newly created branch into `main`.
4. Push `main` to the remote repository.
